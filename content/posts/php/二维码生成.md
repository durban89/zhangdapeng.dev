Google方式

```php
/**
 * 二维码生成器
 * @param $url
 * @param string $x
 * @param string $level
 * @param string $margin
 * @return string
 */
function two_dimensional_code($url,$x ='150',$level='L',$margin='0'){
    return '<img src="http://chart.apis.google.com/chart?chs='.$x.'x'.$x.'&cht=qr&chld='.$level.'|'.$margin.'&chl='.urlencode($url).'" />';
}
```

但是国内的话还是比较慢：记录下一个比较快的，不知道这个是否长期有效

```php
/**
 * 二维码生成器
 * @param $url
 * @return string
 */
```
