实现图片禁止另存为

```js
<script type="text/javascript" >
function stop(){
    return false;
}
document.onkeydown = stop;
document.onselectstart = stop;
document.onmousedown = stop;
document.oncontextmenu=stop;
</script>
```

将以上代码加入<head></head>之间
